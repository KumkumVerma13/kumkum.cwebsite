Iterative Control Structure(Nested Loop)

Practice Questions


Question 1: Write a program print the pattern on the screen i.e. ?
11111
11111
11111

SOLUTION:
#include < stdio.h >

void main() {
int row, col;
for (row = 1; row <= 3; row++) {
     for (col = 1; col <= 5; col++) {
          printf("1");
}
     printf("\n");
    }
}

OUTPUT:
11111
11111
11111
